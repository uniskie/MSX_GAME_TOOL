## 通常マップID と BGMの対応

### MSX版ゲーム中での処理

ファミコン版ではタイルIDからBGMを決定していますが、
MSX版ではSMAP IDからBGMを決定する方法に変更されています。

- (0xC230) が要求する SMAPID + 1 (無効なら0)
- (0x457B) が現在の SMAPID + 1 (無効なら0)

LD (((0xC230) - 1) + 0x457D) でBGMのファイルID取得

``` asm
;
; 切り替え先 （無効なら0、有効ならSMAP ID + 1) を 0xC230 から読み込み、
; BGMテーブルからBGMファイルのIDを取得する。
;
.X4520: 
 LD     A,(#C230)      	;4520: 3A 30 C2
 CP     #00            	;4523: FE 00
 JR     NZ,.X455F      	;4525: 20 38

(中略)

;
; SMAP IDで BGMのファイルID テーブルを参照し、読み込む
;
.X455F: 
 DEC    A              	;455F: 3D
 LD     HL,#457D       	;4560: 21 7D 45
 ADD    A,L            	;4563: 85
 LD     L,A            	;4564: 6F
 ADC    A,H            	;4565: 8C
 SUB    L              	;4566: 95
 LD     H,A            	;4567: 67
 LD     A,(HL)         	;4568: 7E
 ; TPA(読み込み先)に 0xD000 を指定する
 LD     HL,#D000       	;4569: 21 00 D0
 CALL   #5BD7          	;456C: CD D7 5B
 LD     A,(#C230)      	;456F: 3A 30 C2
 LD     (#457B),A      	;4572: 32 7B 45
.X4575: 
 LD     A,#02          	;4575: 3E 02
 CALL   #7E58          	;4577: CD 58 7E
 RET                   	;457A: C9
```

### BGMバグ

ただ、.X457D (Dsk 0xCD7D / MAIN.COM 0x057D)にあるBGM対応テーブルは
何故かファミコン版と違うBGMが指定されている個所があります。
理由は謎です。

ファミコン版と同じにする場合は、

``` dump
;
; SMAP ID と BGM ファイルID の対応表 （修正版）
;

42 42 42 42 42 42 42 42 3E 3E 3E 3E 40 49 49 41
41 41 41 41 41 41 46 46 3E 3E 3E 46 46 49 49 49
49 49 49 49 49 41 41 41 46 46 40 40 40 40 40 4A
4A 4A 4A 4A 45 45 45 45 45 45 45 45 49
```

となります。

## おまけ：ファミコン版準拠でタイルセットからBGMを求める方法

修正テーブルを作成した過程を説明していきます。

ファミコン版ではマップに使用するタイルセットID（マップチップのタイプ）を元にBGMを決定しています。

ですので、

1. MSX版の動作を解析して、マップに使用するタイルセットを決定する処理を追い、
2. マップ（SMAP ID）とタイルセットの対応が一致していることを確認したうえで、
3. タイルセットID と 正しい（ファミコン版と同じ） BGMの対応表を作成。
4. マップごとのBGM を タイルセットID 準拠の BGMに変更します。

### タイルセット読み込み処理の解析

``` asm
;
; SUB??.PIC を読み込む時に呼ばれる処理
;
; (0xC230) が要求する SMAPID + 1 (無効なら0)
;
.X4640: 
 LD     A,(#C230)      	;4640: 3A 30 C2 ;
 DEC    A              	;4643: 3D
 LD     D,#00          	;4644: 16 00
 LD     E,A            	;4646: 5F
 LD     HL,#C980       	;4647: 21 80 C9
 ADD    HL,DE          	;464A: 19
 LD     E,(HL)         	;464B: 5E
 LD     A,E            	;464C: 7B
 LD     (#DC4A),A      	;464D: 32 4A DC
 LD     A,#66          	;4650: 3E 66    ; SUB00.PIC の ファイルID
 ADD    A,E            	;4652: 83
 LD     C,#01          	;4653: 0E 01
 LD     B,#00          	;4655: 06 00
 LD     HL,#0100       	;4657: 21 00 01
 CALL   #5408          	;465A: CD 08 54
 ```

※曲名と使用ダンジョンの不一致について:  
公式サントラで「海底神殿」と題されている楽曲（FC BGM ID: 0x4E）は、ゲーム中のダンジョン「海底神殿」では流れず、ラストダンジョン「過去のカオスの神殿」で演奏されます。
逆に、ダンジョン「海底神殿」で流れるのは「カオスの神殿」（FC BGM ID: 0x4C）です。
