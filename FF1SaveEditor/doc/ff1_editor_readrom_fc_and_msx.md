ファミコン（FC）版ROM（NESファイル）およびMSX版ディスクイメージ（DSKファイル）における各種参照データのアドレス一覧です。

NESファイルのアドレスは、先頭16バイト（`0x10`バイト）のiNESヘッダーを含めたファイル先頭からのオフセットを基準としています。
DSKファイルのアドレスは、1セクタ＝512バイト（`0x200`バイト）計算によるDSK先頭からのファイルオフセット、および格納ファイル名を基準としています。
セクタ番号はすべて16進数表記です。

### 3. マップ用スプライト（乗り物・固定物）の個別詳細アドレス

#### FC版 (Bank 02)
1個あたり16×16ドット（8×8ドット 2bppタイル 4個分 ＝ 64バイト）。
- **飛空艇の影**: PRG `0x09C00` / NES `0x09C10` (1個: 64バイト)
- **北の橋**: PRG `0x09C40` / NES `0x09C50` (1個: 64バイト)
- **海峡（運河）**: PRG `0x09C80` / NES `0x09C90` (1個: 64バイト)
- **船**: PRG `0x09D00` / NES `0x09D10` (2パターン×3方向 = 6個: 384バイト)
- **飛空艇**: PRG `0x09E80` / NES `0x09E90` (2パターン×3方向 = 6個: 384バイト)
- **カヌー**: PRG `0x0A000` / NES `0x0A010` (2パターン×3方向 = 6個: 384バイト)

#### MSX版 (`MSPR.SPR` / セクタ: `0x0414` / DSK: `0x082800`)
1キャラクタあたりスプライト3枚重ね合わせ（120バイト）。反転機能を使用しないため4方向を保持。
- **船**: ファイル内 `0x0000` 〜 `0x03BF` / DSK `0x082800` 〜 `0x082BBF` (4方向×2パターン = 8個: 960バイト)
- **飛空艇**: ファイル内 `0x03C0` 〜 `0x077F` / DSK `0x082BC0` 〜 `0x082F7F` (4方向×2パターン = 8個: 960バイト)
- **カヌー**: ファイル内 `0x0780` 〜 `0x0B3F` / DSK `0x082F80` 〜 `0x08333F` (4方向×2パターン = 8個: 960バイト)
- **飛空艇の影**: ファイル内 `0x0B40` 〜 `0x0BB7` / DSK `0x083340` 〜 `0x0833B7` (1パターン: 120バイト)
- **北の橋**: ファイル内 `0x0BB8` 〜 `0x0C2F` / DSK `0x0833B8` 〜 `0x08342F` (1パターン: 120バイト)
- **海峡（運河）**: ファイル内 `0x0C30` 〜 `0x0CA7` / DSK `0x083430` 〜 `0x0834A7` (1パターン: 120バイト)

### 4. セーブデータ構造一覧（FC版 / MSX版）

セーブデータのサイズは両機種ともに1024バイト（`0x0400`バイト）です。
FC版はバッテリーバックアップSRAM内の `0x0400`〜`0x07FF` に格納されます（`0x0000`〜`0x03FF` は実行中ワークRAM領域で、セーブ時にミラーコピーされます）。
MSX版はユーザーディスク（DSK）のセクタ10〜11（DSKオフセット `0x1400`〜`0x17FF`）に格納され、実行時はメインRAM `0xC000`〜`0xC3FF` に展開されます。

| :------------------------ | :----------------------------------- | :----------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **データ署名**            | `0x04FE`〜`0x04FF` (2B)              | なし                                             | FC版は `0x55, 0xAA`。MSX版は署名なし。                                                                                                                      |
| **チェックサム**          | `0x04FD` (1B)                        | なし                                             | FC版はスロット全加算和 `mod 255` を反転（`sum ^ 0xFF`）。MSX版はなし。                                                                                      |

## MSX版ゲームディスク読み込みへの対応方法

原則：

- DSKのデータアクセスは、FFSayDosTool.py を参考に、セクタ番号範囲をディレクトリエントリから取得してアクセスする
- PICファイルは FFPicTool.py を参考に展開する。
