# ファイナルファンタジー FC版 と MSX版 について

ファミコン（FC）版ROM（NESファイル）およびMSX版ディスクイメージ（DSKファイル）における各種参照データのアドレス一覧です。

NESファイルのアドレスは、先頭16バイト（`0x10`バイト）のiNESヘッダーを含めたファイル先頭からのオフセットを基準としています。
DSKファイルのアドレスは、1セクタ＝512バイト（`0x200`バイト）計算によるDSK先頭からのファイルオフセット、および格納ファイル名を基準としています。
セクタ番号はすべて16進数表記です。

## 3. マップ用スプライト（乗り物・固定物）の個別詳細アドレス

### FC版 (Bank 02)

1個あたり16×16ドット（8×8ドット 2bppタイル 4個分 ＝ 64バイト）。

- **飛空艇の影**: PRG `0x09C00` / NES `0x09C10` (1個: 64バイト)
- **北の橋**: PRG `0x09C40` / NES `0x09C50` (1個: 64バイト)
- **海峡（運河）**: PRG `0x09C80` / NES `0x09C90` (1個: 64バイト)
- **船**: PRG `0x09D00` / NES `0x09D10` (2パターン×3方向 = 6個: 384バイト)
- **飛空艇**: PRG `0x09E80` / NES `0x09E90` (2パターン×3方向 = 6個: 384バイト)
- **カヌー**: PRG `0x0A000` / NES `0x0A010` (2パターン×3方向 = 6個: 384バイト)

### MSX版 (`MSPR.SPR` / セクタ: `0x0414` / DSK: `0x082800`)

1キャラクタあたりスプライト3枚重ね合わせ（120バイト）。反転機能を使用しないため4方向を保持。

- **船**: ファイル内 `0x0000` 〜 `0x03BF` / DSK `0x082800` 〜 `0x082BBF` (4方向×2パターン = 8個: 960バイト)
- **飛空艇**: ファイル内 `0x03C0` 〜 `0x077F` / DSK `0x082BC0` 〜 `0x082F7F` (4方向×2パターン = 8個: 960バイト)
- **カヌー**: ファイル内 `0x0780` 〜 `0x0B3F` / DSK `0x082F80` 〜 `0x08333F` (4方向×2パターン = 8個: 960バイト)
- **飛空艇の影**: ファイル内 `0x0B40` 〜 `0x0BB7` / DSK `0x083340` 〜 `0x0833B7` (1パターン: 120バイト)
- **北の橋**: ファイル内 `0x0BB8` 〜 `0x0C2F` / DSK `0x0833B8` 〜 `0x08342F` (1パターン: 120バイト)
- **海峡（運河）**: ファイル内 `0x0C30` 〜 `0x0CA7` / DSK `0x083430` 〜 `0x0834A7` (1パターン: 120バイト)

## 4. セーブデータ構造一覧（FC版 / MSX版）

セーブデータのサイズは両機種ともに1024バイト（`0x0400`バイト）です。
FC版はバッテリーバックアップSRAM内の `0x0400`〜`0x07FF` に格納されます（`0x0000`〜`0x03FF` は実行中ワークRAM領域で、セーブ時に `0x0400`〜`0x07FF` からミラーコピーされます）。なお、北米版（NES版）もセーブデータのメモリ配置はFC版と同一です。
MSX版はユーザーディスク（DSK）のセクタ10〜11（DSKオフセット `0x1400`〜`0x17FF`）に格納され、実行時はメインRAM `0xC000`〜`0xC3FF` に展開されます。

| データ項目                | FC版 SAVオフセット                   | MSX版 DSKオフセット (RAMアドレス)                | 構造・仕様の差異                                                                                                                                              |
| :------------------------ | :----------------------------------- | :----------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **データ署名**            | `0x04FE`〜`0x04FF` (2B)              | なし                                             | FC版は `0x55, 0xAA`。MSX版は署名なし。                                                                                                                        |
| **チェックサム**          | `0x04FD` (1B)                        | なし                                             | FC版はスロット1024バイト全加算和 `mod 255` を反転（`sum ^ 0xFF`）。計算時は `0x04FD` を0として計算。MSX版はチェックサムなし。                                 |

## 5. FC(JP)版とNES(US)版の内部仕様・アドレス差一覧（セーブデータ以外）

北米NES版（US版）は、ファミコン日本版（JP版）をベースにローカライズされていますが、テキスト領域、メッセージ表示速度設定（RESPONSE RATE）、プロローグのスタートボタンスキップ追加などの仕様変更に伴い、一部のバンクでデータおよびコードの配置アドレスがシフトしています。

### 5.1 各バンクの配置差異の概要

- **Bank 00 〜 Bank 0D（切り替えバンク）**:
  - タイル定義、ワールドマップ、モンスター、戦闘背景、武器・防具性能、初期能力値、戦闘用キャラグラフィック等は**JP版とUS版で完全に同一アドレス**に配置されています。
  - **唯一の例外（Bank 0B）**: 赤魔術士 Lv.21 のMP成長フラグが、JP版は `0x30`（Lv5/Lv6 MP上昇）、US版は `0x31`（Lv1/Lv5/Lv6 MP上昇）となっています。
- **Bank 0E（メニュー・移動中処理バンク）**:
  - メニュー画面へのメッセージ速度（RESPONSE RATE）設定処理の組み込み等により、後半のデータテーブルおよび判定ルーチンが、US版から見て日本版は **+19バイト（`+0x13`）** 後ろへずれています。
- **Bank 0F（固定バンク: CPU `$C000`〜`$FFFF`）**:
  - プロローグのスキップ判定追加やフォント描画ルーチン等の増減により、パレット・ステータス計算ルーチンが、US版から見て日本版は **+143バイト（`+0x8F`）** 後ろへずれています（US版は日本版より `0x8F` バイト前方に配置）。

### 5.4 文字コードおよびフォント体系の差異

- **日本版 (FC)**:
  - 50音かな・カナ・数字・記号を独自文字コード（`0x00`〜`0xFF`）にマッピング。
  - セーブデータ内の名前領域（4バイト）には、濁点・半濁点を1文字に結合した独自コード（`0x48`〜`0x79`）が使用されます。
- **北米版 (NES)**:
  - ASCII配列に準拠した文字コード体系を採用（大文字 `A-Z`: `0x8A`〜、数字 `0-9`: `0x80`〜 等）。
  - ダイアログテキストには容量圧縮のため2文字合成（DTE: Dual Tile Encoding）コードが導入されています。
  - セーブデータ内の名前領域（4バイト）は、ASCIIコードのアルファベット・記号がそのまま格納されます。
