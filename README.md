# MSX_GAME_TOOL

|名前|内容|
|---|---|
|[DISCSTATION              ](DISCSTATION               )|**ディスクステーション MSX**からゲームを切り出すツール|
|[ExternalFDD_Compatibility_Fix](ExternalFDD_Compatibility_Fix)|外付けFDDで動かない**MSX2版 きゃんきゃんバニースペリオール**を動かす起動サポートディスク|
|[FF1SaveEditor](FF1SaveEditor)|**ファイナルファンタジー1 FC版とMSX2版**両対応のセーブデータエディタと、**MSX2版用のBGM割り当て修正パッチ**|
|[KSS_TOOL/RuneWorth       ](KSS_TOOL/RuneWorth        )|**MSX2版 ルーンワース**のディスクイメージから曲データ(mdtファイル)を取り出したり、KSSファイルを作成するツールセット<br><br>**MSXFAN 1995年6月号 付録ディスク#32-1**収録の**アンデッドラインBGM集&MML開発キット一式(UNDEAD.LZH)**があれば、切り出したmdtファイルをMSX-DOSコマンドラインで試聴できます。 |
|[MEGA_UTIL](MEGA_UTIL )|**MSX1/2版 ハイドライド３**、**ガリウスの迷宮**、**パロディウス**、**F1-SPIRIT**に使用するツール。（おまけでコナミ後期MSX1用ソフト汎用クイックセーブツールもアリ）<BR>ROMの後挿しをしてBASICからゲームを起動。拡張ポーズ機能を追加。<BR>1. ゲーム中に状態をまるごとクイック保存・復帰<BR>2. 状態を保存してBASICとゲームを行き来。<BR>3. BASICに戻ってディスクにゲームの状態丸ごと保存・復帰<BR>4. JUKE-BOX（GALIOUS、PARODIUS、F1SPIRIT）、またはキャラクターデータエディット（HYDLIDE3）機能の追加|
|[MSXFAN13_HYDLIDE_PATCH   ](MSXFAN13_HYDLIDE_PATCH    )|**MSXFAN 1992年10月号 付録ディスク#13**収録の**MSX2版 ハイドライド**用置き換え画像データ|
|[RType_MSXROM_To_Ascii16  ](RType_MSXROM_To_Ascii16   )|**MSX版 RType**をASCII16用ROMイメージに変換|
|[SkiCommandPatch](SkiCommandPatch)|**CASIO スキーコマンド**がMSX2以降で暴走する問題の修正|
|[SLAYDOCK_SCC             ](SLAYDOCK_SCC              )|**MSX版 スーパーレイドック**をSCC音源対応させるツール|
|[THE_HOBBIT_TO_DSK        ](THE_HOBBIT_TO_DSK         )|**MSX版 THE HOBBIT**をディスクで実行するツールセット|
|[TRITON_TAPE2DSK          ](TRITON_TAPE2DSK           )|**MSX版 トリトーン テープ版**をディスクから実行するツールセット|
|[YS2EDIT_MSX2             ](YS2EDIT_MSX2              )|**MSX2版 イース２**のディスクの中にあるメッセージデータを表示したり編集するツール|
