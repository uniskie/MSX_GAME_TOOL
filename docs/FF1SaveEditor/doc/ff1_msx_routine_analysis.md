# MSX版 ファイナルファンタジー ルーチン・ワークエリア解析書

本書は、MSX2版『ファイナルファンタジー』における主要実行モジュール（`MAIN.COM`、`BATTLE.COM`、`MENU.COM`、`SMAP.COM`）の内部構造、各サブルーチンの役割、およびモジュール間で共有・参照されるワークエリア（メインRAM領域）の配置と仕様を整理・統合した解析資料です。

---

## 1. 全体アーキテクチャとメモリマップ

### (1) メインRAM メモリマップ概要

MSX版ファイナルファンタジーは、メインRAM 64KByte空間を機能単位で分割し、常駐システム、オーバーレイモジュール、セーブ領域、演奏ドライバ、ハードウェア制御ワークを配置しています。

| メモリ番地          | サイズ      | 用途・役割                                                            |
| :------------------ | :---------- | :-------------------------------------------------------------------- |
| `0x0100` - `0x33FF` | 13,056 Byte | システム一時バッファ・画像展開・汎用ワーク                            |
| `0x3400` - `0x351F` | 288 Byte    | 戦闘時 味方実効バッファ（4人 × 72 Byte）                             |
| `0x3520` - `0x362D` | 270 Byte    | 戦闘時 敵実効バッファ（最大9体 × 30 Byte）                           |
| `0x2A00` - `0x37FF` | 3584 Byte   | ワールドマップ時 スプライトパターン＆カラー（MSPR.SPR）               |
| `0x3700` - `0x3FFF` | 2,304 Byte  | メッセージベクタ・ショップデータ展開バッファ                          |
| `0x4000` - `0x7FFF` | 16,384 Byte | **MAIN.COM 常駐領域**（フィールド移動・描画・サウンド・システム統括） |
| `0x8000` - `0xBCEE` | 15,599 Byte | **オーバーレイ実行領域**（BATTLE.COM / MENU.COM / SMAP.COM 排他実行） |
| `0xBC60` - `0xBCDC` | 125 Byte    | 戦闘制御ワーク（BATTLE.COM 実行時に使用）                             |
| `0xBD00` - `0xBF59` | 602 Byte    | **PSG/BGM演奏ドライバ ワークエリア**（MAIN.COM常駐・常時更新）        |
| `0xC000` - `0xC0FF` | 256 Byte    | セーブデータ：味方キャラクタ基本パラメータ（4人 × 64 Byte）          |
| `0xC100` - `0xC1FF` | 256 Byte    | セーブデータ：味方習得魔法・MPデータ（4人 × 64 Byte）                |
| `0xC200` - `0xC256` | 87 Byte     | セーブデータ：進行フラグ・所持品・位置座標・ギル                      |
| `0xC257` - `0xC28F` | 57 Byte     | ダンジョン階層移動スタック・ワープ制御ワーク                          |
| `0xC400` - `0xC4FF` | 256 Byte    | サブマップ内 NPC管理バッファ（最大16体 × 16 Byte）                   |
| `0xC500` - `0xC7FF` | 768 Byte    | マップタイル属性およびタイルセット定義テーブル                        |
| `0xC800` - `0xC9FF` | 512 Byte    | ワールド・サブマップ移動座標テーブル（`POSIT.TBL` 展開領域）          |
| `0xCA00` - `0xCDFF` | 1,024 Byte  | SayDos ファイル管理セクタテーブル（256エントリ × 4 Byte）            |
| `0xDC00` - `0xDC4E` | 79 Byte     | **システム制御・VDP（V9938）パラメータ・入力状態ワーク**              |

### (4) セーブデータ・パーティ基本情報領域（`0xC000` - `0xC256`）

ユーザーディスクのセクタ 10 - 11 に記録され、ゲーム実行中はメインRAM `0xC000`〜 に常駐する最重要パラメータ群です。

#### ① キャラクタパラメータブロック（`0xC000` - `0xC0FF`: 4人 × 64 Byte）

| オフセット      | サイズ | 格納内容               | 詳細・形式                                                      |
| :-------------- | :----- | :--------------------- | :-------------------------------------------------------------- |
| `+0x00`         | 1 Byte | ジョブID               | 0:戦士, 1:シーフ, 2:モンク, 3:赤魔, 4:白魔, 5:黒魔, 6-11:上位職 |
| `+0x01`         | 1 Byte | 状態異常コード         | 0:正常, bit0:死亡, bit1:石化, bit2:毒                           |
| `+0x02`-`+0x05` | 4 Byte | 名前                   | 独自文字コード4文字。空きは `0xFF`                              |
| `+0x07`-`+0x09` | 3 Byte | 現在経験値             | 24bit ビッグエンディアン                                        |
| `+0x0A`-`+0x0B` | 2 Byte | 現在HP                 | 16bit リトルエンディアン                                        |
| `+0x0C`-`+0x0D` | 2 Byte | 最大HP                 | 16bit リトルエンディアン                                        |
| `+0x10`         | 1 Byte | ちから                 | 1 - 99                                                          |
| `+0x11`         | 1 Byte | すばやさ               | 1 - 99                                                          |

| `+0x13`         | 1 Byte | たいりょく             | 1 - 99                                                          |
| `+0x14`         | 1 Byte | こううん               | 1 - 99                                                          |

### (5) サウンドドライバ ワークエリア一覧（`0xBD00` - `0xBF59`）

`MAIN.COM` 常駐部内のPSG演奏ドライバが使用するワークエリアです。オーバーレイモジュール（BATTLE/MENU/SMAP）実行中もタイマー割り込みで更新されるため、コードや他目的のワークを配置することはできません。

| アドレス            | サイズ   | 用途・格納内容                                           |
| :------------------ | :------- | :------------------------------------------------------- |
| `0xBD00`            | 1 Byte   | サウンドドライバ動作フラグ（1: 再生中, 0: 停止）         |
| `0xBD01`            | 1 Byte   | シーケンスループ更新カウンタ                             |
| `0xBD02` - `0xBD03` | 2 Byte   | 演奏中トラック管理 / SE割り込みプライオリティ            |
| `0xBD04` - `0xBD05` | 2 Byte   | テンポカウンタ / 音長ディレイ制御ワーク                  |
| `0xBD06`            | 1 Byte   | フェードアウト／ボリューム制御フラグ                     |
| `0xBD07`            | 1 Byte   | 現在処理中のチャンネル番号                               |
| `0xBD08`            | 1 Byte   | PSG レジスタ7（ミキサー出力設定）バッファ                |
| `0xBD09`            | 1 Byte   | エンベロープ・音色インデックス                           |
| `0xBD0A` - `0xBD36` | 45 Byte  | **チャンネル0 (PSG Ch.A / メロディ) 制御ブロック**       |
| `0xBD37` - `0xBD63` | 45 Byte  | **チャンネル1 (PSG Ch.B / ハーモニー) 制御ブロック**     |
| `0xBD64` - `0xBD90` | 45 Byte  | **チャンネル2 (PSG Ch.C / ベース・ノイズ) 制御ブロック** |
| `0xBD91` - `0xBF52` | 386 Byte | 効果音(SE)用チャンネルワーク・ポインタスタック           |
| `0xBF53` - `0xBF54` | 2 Byte   | 乱数シード / ピッチモジュレーションワーク                |
| `0xBF55`            | 1 Byte   | チャンネル出力イネーブルマスク                           |

## 2. MAIN.COM（フィールド・システム統括）

### (1) モジュール概要

- ロード先: メインRAM `0x4000` - `0x7FFF`（常駐）
- セクタ位置: 100 - 131（32セクタ、16,384 Byte）
- 役割: メインループ駆動、キー入力監視、フィールド/ダンジョン移動制御、VDPスクロール描画、リソース読み込み、PSG/BGM演奏ドライバの実行管理。

---

### (4) 主要ルーチンの解説

#### ① メインループとイベントディスパッチ（`0x4014`）

毎フレーム呼び出され、入力、移動、スクロール、エンカウント判定、システムキー処理を順次実行します。

```text
0x4014: メインループ先頭
├── 0x6F31: 入力取得 (0xDC1A へ格納)
├── 0x46DA: プレイヤー移動・乗り物・足元タイル処理
├── 0x5663: 歩行アニメーション更新・画面スクロール制御
├── 0x6119: サブマップ内NPC移動更新 (SMAP.COM 0x8003 呼出)
├── 0x406D: Aボタン入力判定 (会話 / 調査 / 宝箱)
├── 0x407F: F1キー判定 (MENU.COM 呼び出し)
├── 0x4121: F2キー判定 (セーブメニュー 呼び出し)
├── 0x4206: SELECTキー判定 (全体マップ MAPDSP.COM 呼出)
├── 0x416C: エンカウントフラグ (0xDC44) 監視 -> 戦闘起動
├── 0x428D: コーネリア北の橋 イベント判定
├── 0x42D3: 固定ボス戦判定 (0xC238)
├── 0x40FD: 海洋固定エンカウント判定 (海賊船)
├── 0x41C0: 移動時毒ダメージ処理 (生存者HP減算)
├── 0x42EF: ランダムエンカウント歩数減算・判定
├── 0x6382: デバッグフック (製品版では即時 RET)
└── JP 0x4014 (ループ)
```

#### ② プレイヤー移動・乗り物・足元タイル処理（`0x46DA`）

- 方向算出: `0xDC1A` のキー入力から移動方向番号（0:上, 1:右, 2:下, 3:左）を算出。
- アドレス計算: 移動先タイルのメモリ番地を算出してタイル属性（`0xC500` テーブル）を取得。
- 分岐: ワールドマップ時は `0x48F9`、サブマップ時は `0x4755` へ分岐。
  - サブマップ（`0x4755`）: 扉（`0x47B9`）、鍵扉（`0x47DB`）、宝箱（`0x47F7`）、ダメージ床（`0x4814`）、ワープ（`0x4A5F`）。
  - ワールドマップ（`0x48F9`）: 徒歩（`0x4916`）、船（`0x494F`）、カヌー（`0x497B`）、飛空艇（`0x49A5`）。

#### 飛空艇着陸判定ルーチン（`0x4D5A`）
```asm
.X4D5A:   CALL .X5E1F                 ; 着陸降下アニメーション
          LD   A, (0C23DH)            ; 足元タイルの属性フラグ取得
          BIT  3, A                   ; ビット3判定 (0: 着陸可 / 1: 着陸不可)
          JP   NZ, .X5DF7             ; 不可なら高度を戻してキャンセル
          JP   .X4A29                 ; 着陸成立・徒歩へ復帰
```

#### ③ マップ遷移・テレポート処理

- `0x4A95`: ワールドマップから街・ダンジョン進入。`POSIT.TBL` の `0x0000` - `0x005F` を参照し、進入先マップIDを設定して `SMAP.COM`（ファイルID: `0x06`）を展開。
- `0x4AE2`: サブマップからワールドマップ脱出。`POSIT.TBL` の `0x0060` - `0x007F` を参照してワールド座標へ復帰。
- `0x4B32`: 階段・階層移動（サブマップ間）。`POSIT.TBL` の `0x0080` - `0x013F` を参照。現在階層を `0xC257` のスタック領域へ退避。
- `0x4B7B`: 脱出魔法（テレポ・ダプター）。退避スタックから親階層情報を取り出して復帰。

#### ④ エンカウント・戦闘起動処理

- `0x42EF`: 歩行ごとに乱数（`0x5085`）を生成し、エリア危険度テーブル（`0x442E`）と比較。成立時に足元タイルIDを `0xDC4B` へ退避。
- `0x4399`: `ENCOUNT.TBL`（ファイルID: `0xD6`）から敵グループを選定。
- `0x43C7`: `BATSCENE.TBL`（ファイルID: `0xD7`）から戦闘編成データ（16 Byte）を `0xDC32` へコピー。
- `0x43EA`: `BATTLE.COM`（ファイルID: `0x08`）を `0x8000` にロードして実行。戦闘終了後は画面を再描画してフィールド復帰。

#### ⑤ パレット フェード制御処理（`0x7300`, `0x7394`）

画面暗転および明転演出を受け持つサブルーチンです。

- **`0x7300`**: パレット フェードイン（明転）
  - `0xDC4E` にウェイト値（`0xC8`）を設定し、サブルーチン `0x7315` を呼び出します。
  - `0x72D0` に目標パレット（`0x72A0`）を退避し、現在のVDPパレットを全色黒（0, 0, 0）で初期化。
  - ループカウンタ `B`（0 - 7）をインクリメントしながら、全16色を目標RGB値まで8段階で加算反映します。
- **`0x7394`**: パレット フェードアウト（暗転）
  - `0xDC4E` にウェイト値（`0xC8`）を設定し、サブルーチン `0x73A9` を呼び出します。
  - `0x72A0` の目標パレット値から、ループカウンタ `B`（0 - 7）に従って各色RGB値を8段階で減算反映し、最終的に全色黒（0, 0, 0）へ遷移させます。

## 3. BATTLE.COM（戦闘システム）

### (1) モジュール概要

- ロード先: メインRAM `0x8000` - `0xBCEE`（オーバーレイ）

- 味方実効バッファ（`0x3400` - `0x351F`: 4人 × 72 Byte）
  - `+0x00`: ジョブID, `+0x01`: 状態異常, `+0x0A`-`+0x0B`: 現在HP, `+0x0C`-`+0x0D`: 最大HP
  - `+0x20`: 攻撃力, `+0x21`: 命中率, `+0x22`: 防御力, `+0x23`: 回避率, `+0x24`: 耐性, `+0x25`: 魔法防御

  - `+0x10`: 耐性, `+0x11`: 魔法防御, `+0x12`: 弱点, `+0x13`: 種族, `+0x17`: 状態異常コード

### (4) 主要ルーチンの解説

#### ① 物理攻撃計算エンジン（`0x94D3`）

- 命中判定値算出: `168 + 攻撃側命中率 - 防御側回避率`。
- 暗闇補正: 攻撃側が暗闇状態なら命中率 -40。防御側が暗闇なら命中率 +40。
- ヒット回数算出: `回数 = 1 + (命中率 / 32)`（最大8ヒット）。
- ヒット判定ループ: 0 - 200 の乱数を生成し、命中判定値以下ならヒット成立。
- ダメージ計算:
  - 単発ダメージ = `(攻撃力 ... 攻撃力*2) - 防御力`（最低保証1ダメージ）。
  - クリティカル成立時（乱数 <= 武器クリティカル率）、攻撃力数値を直接ダメージに加算。
- 武器追加効果（`0x968A`）: 攻撃ヒット時、追加効果属性と状態異常付与判定を実行。

#### ② 魔法・アイテム実行エンジン（`0x9871`）

- 沈黙チェック: 詠唱者が沈黙状態なら魔法不発。
- 魔法データ取得: `BDATA.TBL` から威力、命中率、属性、対象範囲を取得。
- ダメージ・効果ディスパッチ（`0x9D07`）:
  - 攻撃魔法: `ダメージ = (基礎威力 ... 基礎威力*2) - 敵魔法防御`。弱点一致時は1.5倍、耐性保有時は半減。
  - 状態異常魔法: 抵抗乱数判定。耐性属性を持つ対象には無効。
  - 回復魔法: 基礎威力に基づきHP加算（最大HPを超えないようクリッピング）。
  - バフ／デバフ: プロテス（防御上昇）、インビア（回避上昇）、ヘイスト（ヒット回数倍増）を適用。

### (4) 主要ルーチンの解説

#### ① 装備および能力値再計算（`0x8D1F`）

装備変更時、各キャラの基本ステータスと装備品テーブル（`BDATA.TBL`）を参照して戦闘能力値を再計算します。

```text
0x8D1F: 4人分のループ処理先頭
├── 0x8D45: 攻撃力算出
│   └── 基本値（力/2）+ 装備武器の攻撃力
├── 0x8D63: 命中率算出
│   └── 基本値 + 装備武器の命中率補正
├── 0x8D81: 防御力算出
│   └── 装備防具4枠の防御力合計
├── 0x8D9C: 回避率算出
│   └── 基本値（すばやさ）- 装備防具の総重量
└── 0x8DC0: 属性耐性合成
    └── 装備防具4枠の耐性フラグを論理和（OR）合成
```

#### ② フィールド魔法使用（`0x9280`）

- HP回復魔法（ケアル系）: 対象キャラの現在HPを加算。最大HPを超えないようクリッピング。
- 状態異常回復魔法: ポイゾナ（毒ビット解除）、ストナ（石化ビット解除）。
- 移動・脱出魔法:
  - テレポ（`0x9505`）: ダンジョン脱出。親階層スタックから前マップ座標を取り出して復帰。
  - ダプター（`0x95A0`）: 現在ダンジョン最上階へ脱出。

### (4) 主要ルーチンの解説

#### ① 宝箱回収処理（`0x852B`）

- 宝箱判定: `0x8031` で取得した前面タイル属性が `0x04`（宝箱）の場合に起動。
- テーブル参照: `TBOX.TBL`（ファイルID: `0xD3`）から対象宝箱の格納データ（アイテムIDまたはギル値）を取得。
- 所持枠判定:
  - ギルの場合: 所持金（`0xC254`）へ加算（最大999,999ギル）。
  - アイテム・武具の場合: 空きスロット（`0xC018`〜, `0xC01C`〜）を検索して格納。満杯時は警告メッセージ。
- フラグ更新: タイルを空箱IDへ書き換え、VRAM更新要求フラグ（`0xDC4D`）をセット。

#### ② NPC移動AI・歩行制御（`0x86D6`）

- 16体分のループ処理。
- 待機タイマーを減算し、0になった時点で乱数（`0x5085`）から移動方向を決定。
- 移動先タイルの進入可否判定（障害物、壁、プレイヤーとの衝突チェック）。
- 進入可能であれば座標（`+0x0A`, `+0x0B`）を更新し、歩行アニメーション足踏みフラグを切り替え。

#### ③ ショップ制御ルーチン群（`0xA012`）

施設タイル進入時、対応するショップルーチンが呼び出されます。

- **武器屋・防具屋（`0xAD56`）**:
  - `SHOPITEM.TBL`（ファイルID: `0xD4`）から店舗ごとの取扱商品（最大4種）を取得。
  - キャラクターの装備可能ジョブフラグを判定し、装備不可時は警告表示。
  - 購入時は所持ギル減算、対象キャラの空き装備枠へ格納。
  - 売却時は売却対象を選択し、定価の半額を所持ギルに加算。
- **道具屋（`0xB034`）**:
  - ポーション、どくけし、テント等の個数を管理（上限99個）。
- **魔法屋（`0xB133`）**:
  - 習得可能レベル、現在の習得枠数（最大3枠）、ジョブ適性を判定。習得枠満杯時は購入不可。
- **宿屋（`0xB35D`）**:
  - 宿泊料を支払い、パーティ全員のHP・全レベルMPを最大値まで全回復。
  - ユーザーディスクのセクタ 10 - 11 へ現在のセーブデータを書き込み。
- **教会（`0xB4C8`）**:
  - 死亡状態（HP=0 または 死亡フラグセット）のキャラをリストアップ。
  - レベルに応じた寄付金を支払い、HP=1で蘇生。
